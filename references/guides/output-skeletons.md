# Output Skeletons

以下骨架用于指导最终 Markdown 输出怎么写，不是强制逐字照抄。保留章节意图，比保留字面格式更重要。

默认写法要求：

- 除非用户明确要求简版，否则按“结构化详细摘要”生成，而不是只写短纲要。
- 必需章节优先写成有信息密度的 bullets、小节或表格，避免每节只有一句空话。
- 当材料足够时，每个主章节至少包含多个具体事实、例子、证据、数据或行动项。
- 优先保留原材料中的名字、数字、时间、公式、指标、引用和因果关系。
- 对长书优先保留层级结构：`全书 -> 部分 -> 章节`，不要把中层结构压平。
