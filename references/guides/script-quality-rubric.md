# 分镜脚本质量评分层 —— 门过之后,判「好」

> 规范层。`scripts/validate_video_script.py` 的 FAIL/WARN 门是**机械正确性**判定(入场券,只判「不坏」);本文件判**专业质量**(判「好」)。两层分别判定:0 FAIL 不进本 rubric,本 rubric 不过不交付。门过但平庸的脚本——镜头全部中景+static、情绪词偷懒、节奏无弧线——此前可以满门通过,本文件就是拦住它的那层。来源:mouse-lin/frame-smith 仓 showcraft.md(双层验收 + 0-2 分 rubric + 分数段决策),2026-10 吸收。

## 使用时机

`modes/video-script.md` 校验门 0 FAIL 之后、第五步输出之前的「质量自评」小节。来回调整期不跑(与校验门同纪律,只对最终交付负责),定稿那一次必须跑。

## 六个维度(每维 0-2 分,锚点可对照)

| 维度 | 2 分锚点 | 1 分锚点 | 0 分锚点 |
| --- | --- | --- | --- |
| **立意聚焦** | 一句话说得清这套片子要表达什么;每个镜头去掉后立意受损 | 立意说得清,但有个镜头是凑数的 | 说不清想表达什么;或每个镜头都「有点意思」但没有共同方向 |
| **镜头特异性** | 景别/机位/运镜的选择看得出为这条内容服务;特写给了关键细节,远景不面面俱到 | 景别有变化但看不出选择逻辑 | 全部中景 + 几乎 static;或景别随机跳动无叙事意图 |
| **情绪外化姿态化** | 情绪靠姿态/手势/表情/节奏外化;动作链按时间顺序具体 | 姿态化了,但有一两个动作链仍在描述内心状态 | 直接写 sad / nervous / happy 这类内心状态词;或动作抽象到模型无法生成 |
| **视觉连贯** | 光线/色彩/质感跨镜头成立,光源逻辑自洽,冷暖混用有动机 | 大体连贯,有一两处光源或色调跳变 | 相邻镜头像两部片子;冷暖光乱撞且无动机 |
| **节奏弧线** | 有起承转合,高潮镜头有位置,结尾落地;镜头时长有呼吸 | 节奏平稳但无高点,结尾只是停下 | 匀速平推,或结尾停在随机画面 |
| **音频要素克制** | 音频要素按关键事件给:环境音、音乐、台词各自有明确出现位置 | 音频要素都在但铺满每个镜头 | 每个镜头都塞满音乐/音效;或全片无音频要素(大片音画缺失) |

## 分数段决策

| 总分(满分 12) | 判定 | 行动 |
| --- | --- | --- |
| **10-12** | 高质量 | 交付 |
| **6-9** | competent 但平庸 | **找到 0 分项定点修,不要整体重写**;修完重评该维 |
| **≤5** | slop | 回退立意——重读需求输入,不是修补镜头 |

## 修复策略

**按最低分维度修,不往强维堆料。**往 2 分维度继续加料(再加一个炫运镜)救不了 0 分的节奏弧线;先修最低分那维,重评,再决定要不要动下一维。每次只针对一个维度。
