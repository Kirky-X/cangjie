# 运镜术语对照：情绪域与叙事序列

> **表头声明：以下是经验对照，不是定律。** 同一运镜放在不同上下文里，情绪完全可能反着用（缓推近一张熟睡的脸是紧张，推近一份录取通知书是喜悦）；拿不准时回到立意反推——这套视频讲什么事、给人什么感受，再挑服务于它的运镜。

单镜头提示词怎么写见 [`video-prompt-guidelines.md`](video-prompt-guidelines.md)；本文件管跨镜头的运镜选择：什么情绪配什么运镜、最小叙事弧线怎么落到运镜序列。术语保持英文（与提示词工艺一致），情绪与场景用中文。

## 一、运镜情绪对照表

术语取自 [`video-prompt-guidelines.md`](video-prompt-guidelines.md) 五节的镜头语言词表。"类型"列是相邻镜头运镜校验（`scripts/validate_video_script.py` 的"禁连续 3 个同类型"）所用的运动类型划分。

| 术语 | 类型 | 情绪域 | 适用场景 |
|---|---|---|---|
| follows | 跟随 | 陪伴、代入、同行 | 观众跟着角色穿过场景，长镜头交代人物与环境的关系 |
| tracks | 跟随 | 行进、稳定的观察 | 并行跟拍走路/驾车，信息按顺序平稳展开的叙述段 |
| pans | 摇转 | 引导视线、从容铺陈 | 从角色摇到他看见的东西，扫过环境交代空间布局 |
| circles around | 环绕 | 高光凝滞、被注视、仪式感 | 主角的决胜/告白时刻，时间仿佛停住的转折点 |
| tilts | 摇转 | 揭示、敬畏与体量感 | 从细节仰摇到全貌的揭示，仰拍建筑/人物的压迫感 |
| pushes in | 推拉 | 聚焦、紧张升温、亲密 | 情绪落点前逼近面部，发现关键事物的强调 |
| pulls back | 推拉 | 释然、疏离、收束 | 结尾拉远把人物放回环境，告别与落幕 |
| overhead | 视角 | 渺小、宿命、全局在握 | 俯瞰城市/人群，如地图般交代空间关系 |
| handheld | 手持 | 不安、紧迫、纪实 | 追逐、混乱、新闻/纪录片质感的主观视角 |
| ots | 视角 | 对峙、张力、窥视 | 越过肩膀的两人对话，暗中观察的视角 |
| static | 固定 | 冷静、克制、旁观 | 开场定场镜头，让画面内的动作自己说话 |

`ots` 即 over-the-shoulder（过肩），`shots.json` 的 `camera_motion` 写 `ots` 或 `over-the-shoulder` 均可。

## 二、最小叙事弧线的运镜序列模板

`modes/video-script.md` 的起承合（起＝建立场景/人物 → 承＝动作展开/转折 → 合＝结果/情绪落点）可以直接映射到运镜序列。三条默认模板供起点使用，按镜头数裁剪：

**模板 A · 平静叙述型**（治愈/日常/总结性内容）

起 static（定场）→ 承 follows（跟随进入事件）→ 合 pushes in（推近落点收情绪）

**模板 B · 紧张升级型**（悬疑/冲突/新闻事件）

起 overhead（俯瞰交代全局）→ 承 handheld（贴近混乱主体）→ 合 circles around（凝滞在关键瞬间）

**模板 C · 收束释放型**（告别/结局/释然情绪）

起 pushes in（先推近建立牵挂）→ 承 tracks（并行展开过程）→ 合 pulls back（拉远放回环境收束）

使用注意：模板是起点不是答案——某镜头的情绪与运镜冲突时，以情绪为准换运镜；交付校验禁同一类型连续 3 个（如三连 static、三连推近），三条模板本身已避开。
