# 会议纪要格式模板

## 适用场景

- 会议记录整理
- 团队讨论纪要
- 项目评审会议

## 输出结构

```markdown
# 会议纪要 - {会议主题}

## 会议信息

| 项目     | 内容       |
| -------- | ---------- |
| 时间     | {日期时间} |
| 地点     | {会议地点} |
| 参与人数 | {人数}     |
| 参与人   | {姓名列表} |

## 会议内容

### 发言人1: {姓名}

**[时间戳范围]**

{发言内容摘要}

### 发言人2: {姓名}

**[时间戳范围]**

{发言内容摘要}

## 重要结论

1. {结论1}
2. {结论2}

## 关键决策

| 决策事项 | 决策结果 | 负责人   | 截止时间 |
| -------- | -------- | -------- | -------- |
| {决策1}  | {结果}   | {负责人} | {时间}   |

## 待办事项

| 任务    | 责责人   | 截止时间 | 状态   |
| ------- | -------- | -------- | ------ |
| {任务1} | {负责人} | {时间}   | 待开始 |

## 争议点

| 方案    | 争议原因 | 最终结论 |
| ------- | -------- | -------- |
| {方案1} | {原因}   | {结论}   |

---

生成时间: {生成时间戳}
转录方式: {ASR模型}
```

## 质量标准

- 时间戳保留：所有发言有起止时间戳
- 发言人识别：区分不同发言人
- 内容完整性：不遗漏关键讨论点
