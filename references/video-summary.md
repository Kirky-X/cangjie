# 视频总结格式模板

## 适用场景

- 视频课程/教学视频
- 访谈/对话视频
- 产品演示/会议录像

## 输出结构

```markdown
# 视频内容总结 - {标题}

## 基本信息

| 项目         | 内容                  |
| ------------ | --------------------- |
| 视频标题     | {标题}                |
| 时长         | {总时长}              |
| 类型         | {课程/访谈/演示/会议} |
| 视频来源     | {平台/路径}           |
| 音频提取方式 | {ffmpeg}              |
| ASR模型      | {使用的模型}          |

## 内容概览

{2-3句话概括整体内容}

## 视频结构

### 第一部分: {标题}

**时间**: [{开始} - {结束}]

**主要内容**: {内容摘要}

**视觉要点**: {画面关键元素}

**关键台词**:

> "{台词1}"

### 第二部分: {标题}

{同上结构}

## 关键发言人

| 角色    | 姓名   | 出现时间 | 主要内容 |
| ------- | ------ | -------- | -------- |
| {角色1} | {姓名} | {时间段} | {话题}   |

## 核心观点

### 观点1: {标题}

**提出人**: {发言人}

**时间段**: [{开始} - {结束}]

**观点内容**: {观点描述}

**视觉呈现**: {配合的视觉元素}

## 演示步骤（适用于演示类）

| 步骤 | 时间点 | 操作内容 | 注意事项 |
| ---- | ------ | -------- | -------- |
| 1    | {时间} | {操作}   | {注意}   |

## PPT/关键画面（如有）

| 时间点  | 画面内容 | 关键信息    |
| ------- | -------- | ----------- |
| {时间1} | {描述}   | {文字/图表} |

## 亮点摘录

> [{时间戳}] {发言人}: "{精彩语录}"

## 时间线关键节点

| 时间点  | 事件   | 视觉变化 | 意义   |
| ------- | ------ | -------- | ------ |
| {时间1} | {事件} | {变化}   | {意义} |

## 学习要点（课程类）

1. **{要点标题}**: {内容}
2. **{要点标题}**: {内容}

## 结论与启示

{整体结论，对观众的启示}

---

生成时间: {生成时间戳}
音频提取质量: {评估}
转录质量: {评估}
```

## 质量标准

- 时间戳覆盖：每个部分有时间范围
- 视觉描述：包含画面关键元素
- 发言人区分：区分不同发言人
