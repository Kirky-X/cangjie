# 报告总结格式模板

## 适用场景

- 周报/月报/季报
- 项目进展报告
- 研究报告

## 输出结构

```markdown
# {报告标题}

## 报告信息

| 项目     | 内容                 |
| -------- | -------------------- |
| 报告类型 | {周报/月报/项目报告} |
| 时间范围 | {起始} - {结束}      |
| 作者     | {作者姓名}           |
| 数据来源 | {音频/视频/文档}     |

## 概要摘要

{3-5句话概括核心内容}

## 核心发现

### 发现1: {标题}

**背景**: {发现背景}

**内容**: {具体发现}

**影响**: {意义和影响}

## 关键数据

| 指标    | 数值   | 变化趋势 | 备注   |
| ------- | ------ | -------- | ------ |
| {指标1} | {数值} | {趋势}   | {备注} |

## 问题与挑战

| 问题    | 严重程度 | 影响范围 | 建议方案 |
| ------- | -------- | -------- | -------- |
| {问题1} | {程度}   | {范围}   | {方案}   |

## 建议与行动项

### 建议

1. **{建议标题}**: {建议内容}
   - 优先级: 高/中/低
   - 预期收益: {收益}

### 行动项

| 行动    | 负责人   | 截止时间 | 优先级   |
| ------- | -------- | -------- | -------- |
| {行动1} | {负责人} | {时间}   | {优先级} |

## 结论

{核心结论，明确判断}

---

生成时间: {生成时间戳}
```

## 质量标准

- 结构完整：包含摘要、发现、数据、建议
- 数据可验证：关键数据有明确来源
- 建议可执行：每个建议有优先级和负责人
