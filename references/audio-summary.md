# 音频总结格式模板

## 适用场景

- 播客/访谈节目
- 演讲/讲座录音
- 培训课程录音

## 输出结构

```markdown
# 音频内容总结 - {标题}

## 基本信息

| 项目     | 内容             |
| -------- | ---------------- |
| 音频标题 | {标题}           |
| 时长     | {总时长}         |
| 类型     | {播客/演讲/访谈} |
| ASR模型  | {使用的模型}     |

## 内容概览

{2-3句话概括整体内容}

## 关键发言人

| 角色    | 姓名   | 关键观点数量 | 主要话题 |
| ------- | ------ | ------------ | -------- |
| {角色1} | {姓名} | {数量}       | {话题}   |

## 核心观点

### 主题1: {标题}

**时间段**: [{开始} - {结束}]

**发言人**: {发言人}

**核心观点**:

- {观点1}
- {观点2}

**关键引用**:

> "{重要引用}"

### 主题2: {标题}

{同上结构}

## 亮点摘录

> [{时间戳}] {发言人}: "{精彩语录1}"

> [{时间戳}] {发言人}: "{精彩语录2}"

## 时间线关键节点

| 时间点  | 事件   | 意义   |
| ------- | ------ | ------ |
| {时间1} | {事件} | {意义} |

## 结论与启示

{整体结论，对听众的启示}

---

生成时间: {生成时间戳}
转录质量: {评估说明}
```

## 质量标准

- 时间戳覆盖：每个主题有时间范围
- 发言人区分：区分不同发言人
- 引用准确：亮点摘录原文引用
