## 使用规范（这个不需要加入最后的会议纪要文件）

### 文件管理

- **命名规则**：`【会议纪要】{主题}-{YYYY-MM-DD}-v{版本号}.md`
- **存放路径**：`lark/会议纪要/{YYYY-MM}/`
- **版本状态**：
  - `v1.0-draft`：会议结束后1小时内发出的初稿
  - `v1.1-approved`：主持人/核心决策人审核后的定稿
  - `v1.2-final`：行动项全部完成后归档的最终版

### 时效要求

| 阶段       | 时限                    | 责任人        |
| ---------- | ----------------------- | ------------- |
| 初稿完成   | 会议结束后 **1小时内**  | 记录人        |
| 参会者确认 | 初稿发出后 **4小时内**  | 全体参会者    |
| 定稿发布   | 会议结束后 **24小时内** | 主持人/记录人 |
| 行动项回顾 | 下次会议开场 **10分钟** | 主持人        |

### 编写原则（FAR原则）

1. **F - Focused（聚焦结果）**：记录决策与行动，不记录对话过程。不写"张三认为...李四反驳..."，只写"结论为..."。
2. **A - Actionable（可执行）**：每个行动项必须有"做什么、谁来做、何时完成、怎么算完成"四要素。
3. **R - Referencable（可追溯）**：会议ID、行动项编号、风险编号全局唯一，跨会议引用时可直接定位。
4. **闭环跟踪**：下次会议必须回顾上次行动项完成率，目标完成率 ≥ 80%。未完成的行动项需说明原因并重新设定截止时间。

### 删减指南（按会议类型）

| 会议类型          | 必留章节                                                                | 可选章节              | 可删除/简化                          |
| ----------------- | ----------------------------------------------------------------------- | --------------------- | ------------------------------------ |
| **项目启动会**    | 摘要、会议信息、议程与讨论（含决策+行动）、风险、下次会议               | Parking Lot           | —                                    |
| **周期例会**      | 摘要、会议信息、议程与讨论（仅行动项+风险）、下次会议                   | Parking Lot、附件     | 详细决策上下文（可简化为1句）        |
| **竞品/调研分析** | 摘要、会议信息、议程与讨论（信息要点+行动）、附件                       | Parking Lot           | 风险、详细决策                       |
| **产品规划会**    | 摘要、会议信息、议程与讨论（含决策+行动+分歧）、风险、Parking Lot       | 附件                  | —                                    |
| **头脑风暴**      | 会议信息、议程与讨论（仅记录想法主题，不记决策）、Parking Lot、下次会议 | —                     | 决策、风险、附件（除非当场产生决策） |
| **决策评审会**    | 摘要、会议信息、议程与讨论（决策+分歧+行动）、风险                      | Parking Lot、下次会议 | —                                    |
