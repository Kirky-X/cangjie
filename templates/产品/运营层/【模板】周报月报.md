## 0. Document Guide

### 0.1 Document Purpose & Scope

**Weekly/Monthly Report answers:** "What did we do this period, how's the progress, any blockers, and what's the plan next" — A periodic sync tool for teams and individuals.

**Applicable Scenarios:**

- ✅ Individual weekly / monthly report
- ✅ Team weekly / monthly report
- ✅ Department routine report
- ✅ Cross-team progress sync
- ❌ Project retrospective (use retrospective report)
- ❌ Performance summary (use performance process)
- ❌ Detailed technical plan (use TRD)

### 0.2 Writing Principles

| Principle | Description |
| :--------------- | :------------------------------------------------------ |
| **Result-Oriented** | Describe deliverables and impact, not a diary |
| **Data-Driven** | Use numbers, avoid "completion rate is roughly similar" |
| **Risk-Exposed** | Blockers and risks must be explicitly exposed, no hiding |
| **Concise First** | Single weekly report ≤ 1 page, monthly report ≤ 2 pages |
| **Traceable** | Link to OKR / Project / Issue for future verification |
